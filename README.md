# Muzzayan Tensile Engineering (MTE)

Pakistan's Premier Tensile Membrane Structures, Industrial Steel Sheds & Cantilever Car Parking Shades.

## Overview
This modern web application is a complete, enhanced, and redesigned platform for **Muzzayan Tensile Engineering (MTE)**. Every piece of technical data, project specification, fabric parameter, and engineering workflow from `tsptensile.com` has been preserved, thoroughly rebranded, and enhanced with a modern luxury architectural layout.

---

## 🌟 Key Features & Unique Additions

1. **Branding & Identity**:
   - Company Name: **Muzzayan Tensile Engineering (MTE)**
   - Acronym: **MTE**
   - Stamped SEO schema and metadata for nationwide discovery across Pakistan.

2. **Luxury Architectural Color Palette & Theme**:
   - Deep Navy Titanium (`#060B18`, `#0B132B`)
   - Metallic Warm Champagne Gold & Amber (`#D4AF37`, `#F59E0B`)
   - High-contrast clean cards with glassmorphic depth (`backdrop-blur-md`).
   - Dynamic 3D **Tensile Membrane Canvas Animation** simulating real hyperbolic paraboloid cables and interactive nodes.

3. **Interactive Online Cost Estimator / Calculator**:
   - Instant price calculations in PKR based on project type, vehicle bays, covered square footage, and fabric grade (Australian HDPE, German Mehler PVDF, French Serge Ferrari, PTFE).
   - Direct 1-click quote export to WhatsApp with all specs pre-filled.

4. **Cantilever vs Traditional 4-Post Shed Comparison**:
   - Interactive breakdown highlighting zero door-ding hazards, wide turning angles, and DHA/Bahria compliance.

5. **Engineering & Fabric Inspector**:
   - Side-by-side technical specification tool comparing German Mehler, Serge Ferrari, HDPE, PTFE, and ETFE.

6. **100+ Projects Portfolio Gallery**:
   - 12 comprehensive landmark projects with category filtering (Commercial, Residential, Industrial, Government, Sports) and interactive modal zoom view.

7. **4-Step Execution Workflow**:
   - Step 01: Listen & Measure (Free site survey)
   - Step 02: Form & Geometry (3D CAD & FEA)
   - Step 03: Fabricate with Care (CNC cutting & galvanizing)
   - Step 04: Install & Tension (Calibrated tensioning & handover)

8. **Regional City Desks**:
   - Specialized pages for Lahore, Islamabad, Rawalpindi, and Karachi with local housing societies, climate ratings, and local office contact numbers.

9. **Direct WhatsApp & Free Site Survey Booking Modal**:
   - Floating WhatsApp button and booking modal allowing clients to schedule free laser measurements across Pakistan.

## 🚀 Running the Website

### Option 1: Double Click `start.bat`
Double click `start.bat` in this folder to launch the production preview server at `http://localhost:3000`.

### Option 2: Run via Terminal
```bash
# To run live development server:
npm run dev

# To build production bundle:
npm run build

# To preview production build:
npm run preview
```

### Production Files
The fully built and optimized static files are in the `dist/` directory, ready to deploy to any hosting provider (Vercel, Netlify, cPanel, Cloudflare Pages, etc.).
